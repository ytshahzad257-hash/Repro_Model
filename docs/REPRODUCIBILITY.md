# Reproducibility

This package is the independent reconstruction used by the revised manuscript.

## Clean execution

    python -m venv .venv
    .venv\Scripts\activate
    python -m pip install -e '.[dev]'
    python -m pytest -q
    python experiments/run_all.py

The full command writes generated JSON, CSV, Markdown, LaTeX, figure previews, witnesses, metadata, the reconstruction consistency report, and a manifest. All stochastic inputs come from experiments/seeds.json.

The current release records the exact Python and platform metadata for each generated experiment. The manuscript reports the Python reconstruction values generated by this package. The original historical seed stream and original generator were not supplied, so the results are repeatable reconstruction results rather than an exact replay of an unavailable historical run.

## TLA+

The TLA+ modules and configurations are included as a separate reference specification. No TLC jar is bundled, and TLC was not available in the environment used for the current revision. Set TLA2TOOLS_JAR to a locally obtained jar and run:

    python scripts/run_tlc.py

The current manuscript does not claim Python/TLC agreement. A machine-readable TLC export is required before any future cross-checker claim is made.

## Interpretation

results/expected/ contains assertions for the current reconstruction and is never imported by the model. results/historical_paper_assertions/ preserves the earlier paper values for comparison. Differences between those historical assertions and current generated results are provenance evidence, not a reason to tune guards or hardcode outputs.

The formal guarantees remain conditional on the trusted policy authority, admission mediator, recorder, evidence store, review interface, release gate, scheduler, and the declared observation boundary. The artifact is not a refinement proof for a production agent runtime.
